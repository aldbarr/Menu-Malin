# Menu Malin

Menus de la semaine bâtis sur les actions Migros, Coop, Denner et Lidl, avec une liste de courses partagée par foyer.

- `index.html` : l'application (une seule page).
- `deals.json` : les actions de la semaine.
- `netlify/functions/liste.mjs` : l'API de la liste partagée (stockage Netlify Blobs).

Pour partager la liste : onglet Courses, bouton « Partager la liste », puis envoyer le lien. Toute personne qui a ce lien peut lire et modifier la liste de ce foyer.
